Списки в Python

шпаргалка создание, добавление, удаление, поиск и другие полезные штуки

Что такое список?

Список — это упорядоченная коллекция элементов. Внутри могут быть числа, строки, другие списки и даже разные типы вместе. Списки изменяемые — можно добавлять, удалять и заменять элементы.

# Создание списков
fruits = ["яблоко", "банан", "вишня"]
numbers = [10, 20, 30, 40]
mixed = [1, "два", 3.0, True]
empty = []                    # пустой список
nested = [[1, 2], [3, 4]]     # список списков
В Python списки пишутся в квадратных скобках [ ], элементы разделяются запятыми. Порядок элементов сохраняется.

Добавление элементов

append(x)
Добавляет один элемент в конец списка. Меняет исходный список.
a = [1, 2]
a.append(3)
# a → [1, 2, 3]
extend(iterable)
Добавляет несколько элементов из другого списка (или строки, кортежа) в конец.
a = [1, 2]
a.extend([3, 4])
# a → [1, 2, 3, 4]
insert(i, x)
Вставляет элемент x на позицию с индексом i. Остальные сдвигаются вправо.
a = [10, 20, 30]
a.insert(1, 15)
# a → [10, 15, 20, 30]

Удаление элементов

remove(x)
Удаляет первый элемент со значением x. Если такого нет — ошибка ValueError.
a = [1, 2, 3, 2]
a.remove(2)
# a → [1, 3, 2]
pop([i])
Удаляет и возвращает элемент по индексу i (по умолчанию последний).
a = [10, 20, 30]
x = a.pop()   # x = 30, a = [10,20]
y = a.pop(0)  # y = 10, a = [20]
del a[i]
Удаляет элемент по индексу или срез. Не возвращает значение.
a = [5, 6, 7, 8]
del a[1]     # a → [5, 7, 8]
del a[0:2]   # удалить срез
clear()
Очищает весь список, делает его пустым.
a = [1, 2, 3]
a.clear()
# a → []

Поиск, индексы и длина

index(x)
Возвращает индекс первого вхождения элемента x. Ошибка, если не найден.
a = ["a", "b", "c"]
i = a.index("b")  # i = 1
count(x)
Считает, сколько раз элемент x встречается в списке.
a = [1, 2, 2, 3]
n = a.count(2)   # n = 2
len(a)
Встроенная функция — длина списка (количество элементов).
a = [10, 20, 30]
print(len(a))    # 3
in / not in
Проверка наличия элемента в списке. Возвращает True или False.
a = [1, 2, 3]
if 2 in a: print("есть")

Сортировка и изменение порядка

sort()
Сортирует список на месте (по возрастанию). Можно указать reverse=True для убывания.
a = [3, 1, 2]
a.sort()          # [1, 2, 3]
a.sort(reverse=True) # [3, 2, 1]
reverse()
Разворачивает список (меняет порядок на обратный).
a = [1, 2, 3]
a.reverse()      # [3, 2, 1]
sorted(a)
Возвращает новый отсортированный список, исходный не меняется.
a = [3, 1, 2]
b = sorted(a)    # b=[1,2,3], a без изменений
copy()
Создаёт поверхностную копию списка. Полезно, чтобы не менять оригинал.
a = [1, 2, 3]
b = a.copy()     # b — новый список
Важно: методы append(), remove(), sort(), reverse(), clear() и insert() изменяют сам список и возвращают None. Не пиши a = a.append(5) — так ты потеряешь список!

Срезы (часть списка)

С помощью срезов можно получать подсписки, а также изменять или удалять сразу несколько элементов.

a = [0, 1, 2, 3, 4, 5]

# Получение среза
b = a[1:4]      # [1, 2, 3]  (с 1 по 3, не включая 4)
c = a[:3]       # [0, 1, 2]  (с начала до 2)
d = a[3:]       # [3, 4, 5]  (с 3 до конца)
e = a[::2]      # [0, 2, 4]  (каждый второй)
f = a[::-1]     # [5, 4, 3, 2, 1, 0] (разворот)

# Изменение через срез
a[1:3] = [10, 20]   # a → [0, 10, 20, 3, 4, 5]
a[2:4] = []         # удалить элементы с индексами 2 и 3

Полезные штуки

max() / min()
Максимальный и минимальный элемент списка.
a = [5, 1, 9]
print(max(a))  # 9
print(min(a))  # 1
sum()
Сумма всех чисел в списке.
a = [1, 2, 3]
print(sum(a))  # 6
list()
Превращает строку (или другой итерируемый объект) в список.
s = "привет"
chars = list(s) # ['п','р','и','в','е','т']
+ (конкатенация)
Объединяет два списка в новый.
a = [1, 2]
b = [3, 4]
c = a + b    # [1,2,3,4]
* (повторение)
Повторяет список несколько раз.
a = [0] * 3
# [0, 0, 0]

Примеры для закрепления

1. Добавляем и удаляем

tasks = ["учёба", "спорт", "чтение"]
tasks.append("отдых")        # ["учёба", "спорт", "чтение", "отдых"]
tasks.remove("спорт")        # ["учёба", "чтение", "отдых"]
tasks.insert(0, "завтрак")   # ["завтрак", "учёба", "чтение", "отдых"]
last = tasks.pop()           # last = "отдых", список без него

2. Поиск и проверка

numbers = [8, 3, 15, 3, 7]
print(3 in numbers)          # True
print(numbers.count(3))      # 2
print(numbers.index(15))     # 2

3. Сортировка и копия

grades = [4, 5, 3, 4, 5]
copy_grades = grades.copy()
grades.sort()
print(grades)        # [3, 4, 4, 5, 5]
print(copy_grades)   # [4, 5, 3, 4, 5] (не изменился)
Запомни: append — в конец, remove — удалить по значению, pop — удалить по индексу (и вернуть). Если нужно удалить по индексу, но без возврата — используй del.

Коротко: что возвращают методы

  • append(x) → None (меняет список)
  • remove(x) → None (меняет список)
  • pop(i) → удалённый элемент
  • index(x) → индекс (число)
  • count(x) → количество (число)
  • sort() → None (сортирует на месте)
  • reverse() → None (разворачивает на месте)
  • copy() → новый список
  • clear() → None (очищает)
